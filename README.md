# IslandCore-Issues — Reporte de errores

Este repositorio es exclusivamente para **reportar errores y sugerencias**
de IslandCore (mod de servidor) e IslandCore Client (mod de cliente).

El código fuente de ambos proyectos es privado y no está disponible
públicamente.

## Cómo reportar un bug

Abre un nuevo [Issue](../../issues/new) e incluye, si es posible:

- Versión del mod (servidor y/o cliente)
- Pasos para reproducir el problema
- Qué esperabas que pasara, y qué pasó en su lugar
- El log de error, si lo tienes (copia el texto o adjunta el archivo)

## Sugerencias

También puedes abrir un Issue para proponer nuevas funcionalidades o
mejoras.
